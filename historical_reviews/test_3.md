# Historical Review — Test 3

## Source
- Original script: `artifacts/test3.py`
- Historical position: follows Test 2.
- Script title: `LEARNED STRUCTURE STORAGE — SELF-CONTAINED BENCHMARK`

## Purpose
Test 3 responds directly to several problems exposed by Test 2. It abandons block-specific autoencoder latents and returns to causal prediction, where predictor state can be derived from byte history already available at the decoder.

It asks whether learned structure can generalize from a training section to unseen continuation data while every residual byte, model byte, and metadata cost is counted.

## Design
The benchmark locally generates three 1,000,000-byte datasets:

1. structured natural-ish text;
2. source-code-like text;
3. deterministic mathematical data generated from a compact mixture of sine/cosine functions.

Each dataset is split 75%/25% into training and held-out sections. The neural model and context model learn only from the training section.

The held-out section is predicted using four approaches:

- previous-byte predictor;
- four-byte context predictor;
- neural categorical predictor;
- simple hybrid averaging the previous-byte and neural predictions.

For every predictor, an exact modulo-256 residual is formed and zlib-compressed. Reconstruction is checked exactly and the held-out reconstruction is SHA-256 verified.

The neural predictor is:

`4 normalized context bytes → 64 → 64 → 256 logits`

and is trained with categorical cross-entropy.

## What progressed from Test 2
Test 2 introduced whole-region learned latent representation, but a standalone decoder had no way to obtain each block's source-dependent latent vector without already possessing the source block.

Test 3 removes that requirement. Predictor state is now a deterministic function of byte history available from the source/reconstructed stream. In conceptual terms:

`shared learned model + decoder-known history → prediction → exact residual`

This is an important answer to Test 2's latent-communication problem: rather than transmit an independent latent state for every region, derive useful state from information the decoder can reproduce.

## Benchmark improvements
Test 3 makes several methodological improvements:

- held-out data is never used for neural training;
- the context model is also built only from training data;
- multiple structurally different datasets are tested;
- exact residual reconstruction is verified;
- held-out hashes are checked;
- neural model storage is measured;
- context-model storage is estimated and charged;
- metadata is charged;
- residual entropy, zero rate, MSE/MAE, and compressed size are reported.

This applies Test C's core accounting lesson more symmetrically: learned structure that is not reconstructible for free must be represented in the storage cost.

## Mathematical dataset significance
The mathematical dataset is deliberately generated by a compact deterministic function despite producing a much larger byte stream. It therefore probes a central Neural Compression idea: a large literal sequence may have a much smaller underlying generative description.

Test 3 does not prove recovery of that generating equation, but it explicitly places compact generative structure inside the benchmark target.

## Hybrid significance
The hybrid predictor simply averages the previous-byte and neural predictions. It is primitive, but conceptually important: different predictors may capture different structural regularities, and a combined strategy may exploit more than a single representation mechanism.

In hindsight this is an early precursor to later work on multiple states, specialization, local strategy selection, and combining distinct structural signals.

## Remaining accounting limitation
The printed final comparison is still not a clean standalone compression comparison. Predictor residual totals represent only the 25% held-out region, while the zlib baseline is computed over the entire 1,000,000-byte dataset.

Thus `held-out residual + model + metadata` is compared against `zlib(full dataset)`, which mixes coding domains.

A fair shared-model evaluation would compare against `zlib(held-out data)`. A fair complete standalone-file representation would also need to account for whatever information makes the trained model available, including the training prefix if it is source-specific.

Test 3 therefore improves the scientific controls substantially but does not completely resolve total-file accounting.

## Preserved-result status
The script is preserved. Repository search has not yet located an authoritative historical console output/result for Test 3, so numerical winner claims are not made in this review.

## Retrospective conclusion
**Strong methodological progression; decoder-state problem substantially resolved; final storage-domain accounting still incomplete.**

Test 3 demonstrates a key architectural direction: useful predictive state can be derived from history that the decoder also possesses, avoiding the need to transmit source-dependent local latents separately.

Historical transition:

`learned structural representation requiring transmitted local state`

→

`shared learned structure + decoder-reconstructible state + exact correction`

It also broadens the research question from one file to several classes of structured information and explicitly tests data whose large byte sequence originates from a compact mathematical process.
