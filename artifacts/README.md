# Research Artifacts

This directory contains selected experiment artifacts preserved as evidence for the research log.

Artifacts are imported selectively rather than copying the entire ChatGPT Project. The goal is to preserve files that materially support a research observation, hypothesis, rejection, or architectural decision.

Import order is currently **newest-to-oldest** so that we can anchor the current state first and progressively reconstruct how we arrived here.

Raw experiment files should be preserved without modification whenever possible. Interpretation belongs in `RESEARCH_LOG.md`; the artifact remains the evidence.
