# Neural Compression — Generation Sampling Audit

A read-only decoding experiment for the existing dense, low-rank, and latent/shared-constructor latent_transformer_v0 checkpoints. It does not train, modify, or overwrite checkpoints.

## Run

From the repository root:

~~~bash
HSA_OVERRIDE_GFX_VERSION=10.3.0 python generation_sampling_audit.py --device auto
~~~

The script reuses the five fixed diagnostic prompts and four held-out prompts sampled by generation_audit.py. It adds temperature sampling at 0.7, 0.9, and 1.0, plus nucleus (top-p) sampling at 0.90 and 0.95. Three deterministic sampling seeds are used per prompt and sampling configuration. The default output length is 128 bytes.

With all nine prompts, defaults produce 432 generation cases: one greedy case plus fifteen seeded sampling cases per prompt, for each of three models.

Optional controls:

~~~bash
python generation_sampling_audit.py --device cpu --seeds 1 --new-bytes 64
python generation_sampling_audit.py --run-root runs/latent_transformer_v0 --heldout-prompts 0
~~~

Use --dense, --lowrank, or --latent to override a checkpoint path. --seed changes the held-out prompt sample and deterministic sampling-seed family.

## Measurements

Each continuation records unique-byte fraction, distinct bigram fraction, repeated trigram rate, whitespace and printable-byte fractions, UTF-8 validity, replacement-character count, raw next-byte entropy, filtered sampling entropy, and raw/filtered top-1 probability. Exact generated bytes are retained as hexadecimal alongside readable text.

The JSON report aggregates results by model, strategy, and prompt. It also measures byte-position agreement between independent seeds for the same prompt and strategy.

Raw entropy describes the unmodified model distribution at temperature 1.0. Sampling entropy describes the distribution actually sampled after temperature and optional top-p filtering.

## Correctness and inference

The custom greedy decoder is checked against TinyLM.generate() for an identical short continuation; a mismatch stops the run.

The latent model uses the existing inference_cache.py all-factor cache only after cached and uncached logits are verified bit-identical on a probe prompt. The cache size is recorded. No autoregressive KV cache is implemented or enabled; that remains a separate optimization question.

## Tests

~~~bash
python test_generation_sampling_audit.py
~~~

## Output and interpretation

Timestamped JSON and TXT reports are written under runs/generation_audit/. Existing reports and checkpoints are never overwritten.

This is a decoding diagnostic, not a training benchmark or a claim about general language ability. Sampling can make output more varied without making it more accurate or coherent. Interpret diversity, entropy, UTF-8 validity, and human-readable continuation together; no single metric is a quality score.
